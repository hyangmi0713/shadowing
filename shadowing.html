3자막 붙여넣기 → 문장 나누기

자막은 어디서 가져오나요?
  1. PC의 YouTube에서 영상 아래 설명 → '스크립트 표시'를 누르세요.
  2. 스크립트 창의 내용을 전부 드래그해서 복사 → 위 칸에 붙여넣기.
  3. .srt / .vtt 자막 파일 내용도 그대로 붙여넣을 수 있어요.
  4. 휴대폰에서는 자막 다운로드 사이트(예: DownSub)에 영상 주소를 넣고 SRT 파일을 받은 뒤, '📂 자막 파일 불러오기'로 고르세요.
자막이 없으면 아래 '초 단위로 자르기'로 나눈 뒤, 각 문장의 ✎ 버튼으로 텍스트를 직접 적으면 채점돼요.
